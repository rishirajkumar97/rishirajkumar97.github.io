Stock Market Data Viewer

  • Tech Stack: Ruby on Rails, Ruby, CockroachDB, VueJS, GCP (App Engine), REST API's
  • Github URL: Project Link

Utilised microservices architectures to implement 3 seperate services one for authentication across the app, one for pulling in real time stock data from third party api, one for pulling in company related news and finance metrics.

Utilised a builder pattern for building the backend services. Achieved CI/CD via trunk based deployment by using github actions.

Configured Secrets in the Github CI pipeline securely to deploy the app directly to GAE without user internvention on a master branch push. Utilized VueJS on front end for simiple and neat UI.
